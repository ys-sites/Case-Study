# Solution Architecture — Option B: Integrated flow package: shared visibility, appointments, AI-assisted yard planning
1. **Measure**: instrument the constraint; establish baseline 105.6 % of capacity with variance.
2. **Intervene**: implement integrated flow package: shared visibility, appointments, ai-assisted yard planning at the binding constraint first (H1 pilot), then scale (H2).
3. **Control**: KPI dashboard with leading indicators (variance, availability) and lagging result (year-5 yard utilization if nothing changes).
4. **Sustain**: standard work, O&M plan (CAD $1,300,000/yr), benefit tracking owned by operations.
